## Главное меню

Референс компоновки — `src/app/main-menu/page.tsx` из коммита `70ad601`: большая ведущая плитка и четыре крупных раздела рядом. Восстановлена эта иерархия, сохранён актуальный `useTodayDashboard` и его выбор следующего шага, ограничения знакомств, состояния пары, уведомления и продолжение занятий. Старые запросы и устаревшая логика из исторического коммита не возвращались.

На ширине от 1024 px главный шаг занимает левую половину, справа находится сетка 2 × 2. Для пользователя с парой доступны «Мы» и общая жизнь, а библиотека и активности вынесены в следующий ряд. На небольших экранах карточки складываются в одну колонку. Служебные действия находятся после основных разделов.

## Тесты и личные анкеты

- Каталог разбит по темам с крупными ссылками на формы и явными статусами. Анкеты, личные результаты и практики разделены вкладками, чтобы весь материал не занимал одну длинную страницу. Скрытые панели сохраняются смонтированными: переключение не стирает введённую заметку.
- В новом прохождении вопрос занимает отдельную рабочую область. На широком экране этапы закреплены слева, на узком раскрываются из компактной сводки. Прогресс отражает сохранённые ответы на доступные этапы.
- Варианты ответа имеют собственную поверхность, видимые radio, рамку и выбранное состояние. Длинные русские варианты переносятся; формулировки опубликованных заданий и ответов не сокращались.
- Причины пропуска доступны в отдельном раскрываемом блоке. Сохранение, объяснение и пауза отделены от вариантов. Переходы сохраняют действующую защиту несохранённых изменений.
- В прежних личных анкетах и измерительных тестах рабочая колонка ограничена `50rem`. Числовые и текстовые ответы получили тактильные поверхности, видимый прогресс и состояние отправки. Автопереход прежних коротких анкет сохранён и пояснён.
- Личный результат показывает понимание, учебное выполнение и описанное применение отдельно. Неизвестность, устаревшие и спорные основания остаются видимыми, детали и история раскрываются по запросу.

## Визуальные правила

Основной профильный навык: [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), установлен локально в `C:/Users/Admin/.codex/skills/ui-ux-pro-max`. Дополнительная проверка визуальной иерархии — [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md).

Из UI UX Pro Max применены конкретные результаты поиска `claymorphism`, `touch spacing`, `loading buttons`, `readable form progressive disclosure`. Автоматическое предложение маркетинговой страницы и детских шрифтов не подходит существующему продукту; сохранены его цвета, шрифты и маршруты. Поиск `CSS modules` в разделе Next.js навыка не дал подходящего результата; правила CSS взяты из документации установленного Next.js 16.3.

Палитра использует существующие сливовый акцент `#983864`, тёмный текст `#593347`, светлую поверхность `#fffdf8`, розовые, мятные и медовые плитки. Глубину передают верхняя светлая грань, нижний край и тени. Нажатие уменьшает тень и смещает элемент вниз; неинтерактивные карточки не поднимаются при наведении. Состояние выбора видно по radio/рамке, а не только по цвету. Числовые ответы разделяет минимум 8 px; стандартные кнопки имеют высоту не менее 48 px.

Основной текст — около 16 px, длина строк вопроса ограничена, важные навигационные подписи на телефоне не уменьшаются до 12 px. При `prefers-reduced-motion` сдвиги отключены, выбранное состояние сохраняется. CSS форм подключается из `globals.css`, чтобы существующие проверки компонентов через Node/tsx не зависели от загрузчика CSS Modules. У меню используется локальный CSS Module.

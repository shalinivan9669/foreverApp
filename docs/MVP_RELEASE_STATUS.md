## Recorded release evidence

- `npm run integration:two-user-mvp` passed against `rs0`: one pair, two claims, two weekly check-ins, one cycle, three snapshots, one recommendation decision, one completed activity, nine notifications, ten sanitized audit events, and no privacy assertion failure. Its independent cleanup audit found zero documents across 21 collections.
- `npm run selfcheck:reliability-reconciliation` passed primary-commit recovery, same-key retry, expired-lease takeover, changed-hash conflict, uncertain completion persistence, a fixed eight-row expired queue, more-than-batch progression, and poison-row isolation without duplicate effects.
- Release DB, privacy, billing-ordering, and like-idempotency integrations passed transaction/concurrency, notification ownership, pair entitlement ordering, owner export/reversible deletion request, and intrinsic like replay/conflict behavior; each isolated DB cleaned all documents.
- Release preflight passed 47 current invariants across the complete 31-collection index registry. A fresh database moved from `missing=95` to zero using explicit additive application. A legacy fixture first proved that `{ userId, weekKey }` uniqueness blocks release, then the explicitly flagged migration removed it and moved remaining drift from `missing=92` to zero; both fixtures were deleted after verification.
- Final synthetic load smoke used a 3.5-year hot-pair history and concurrency 12 for dashboard, recommendation, activity completion, notification/history pagination and related paths. All eight scenarios produced zero errors/conflicts and no duplicate canonical records/effects. Exact latency/query-plan evidence is in `SCALE_READINESS.md`.
- A post-fix production browser smoke on 2026-08-10 rendered the Russian Discord-reconnect boundary without console warnings/errors, exercised the retry handler and `/join` back navigation, and found no horizontal overflow at a 390x844 viewport. It does not substitute for a real Discord iframe, signed-session, notch/safe-area, or on-screen-keyboard run.
- `npm audit --omit=dev` reports zero vulnerabilities after compatible upgrades to Next 16.3 and Mongoose 8.24.2. The dependency lockfile change is expected and reviewed as part of that upgrade.

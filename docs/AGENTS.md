# AGENTS

Docs must be short, indexed, and navigable.

## Rules

- Prefer updating existing docs over creating duplicates.
- `docs/INDEX.md` is the navigation root.
- Do not create long audit reports unless explicitly requested.
- Archive or link old problem docs instead of duplicating guidance.
- Keep docs practical for task execution.
- After meaningful changes, append a short note to `docs/CHANGELOG.md`.
